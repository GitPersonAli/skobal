# Information architecture

Decide how users find, recognize, and return to their work. Give each contributor the same inventory of user jobs, terms, and entry points. Ask each for a grouping principle, a small navigation map with real labels, and the route to the same common task and less frequent task.

The manager tests each map from the user's starting point, including a direct link or return visit where relevant. Trace ambiguously placed actions and the cost of a wrong first choice. Hand the selected map, labels, and unresolved findability questions to UX and visual design. Share any changed entry points with engineering.
