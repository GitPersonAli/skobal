# Motion and micro-interactions

Decide what feedback makes a change of state understandable. Give each contributor the same transition or interaction. Ask what the user needs to perceive, what triggers the feedback, what happens on interruption or rapid repetition, and how reduced motion communicates the same outcome.

The manager checks whether each proposal helps someone understand the state while keeping the next action responsive. Static feedback can be the selected treatment. Hand UX and engineering a compact interaction specification with trigger, visible result, timing when needed, interruption behavior, and reduced-motion equivalent.
