# Visual and UI design

Decide what people see and act on first. Give contributors the same critical screen, realistic content, viewport, and existing brand or design system. Ask for distinct treatments of the hierarchy with the same data, including one demanding state such as a long label, dense list, or validation error. Use the fidelity the brief calls for.

The manager compares legibility, focus order, action prominence, contrast, and fit with the product. Hand off the selected screen or layout specification, component states, and responsive behavior. Resolve changes to wording or action priority with the teams that own those decisions.
