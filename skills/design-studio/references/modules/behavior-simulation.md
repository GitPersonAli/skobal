# Behavior simulation

Use when the brief asks how a group might respond under a changed condition. Frame one scenario question, such as how a switch from chat commands to a menu might affect peer advice. Identify the baseline, changed condition, assumptions, and which design decision the comparison could inform.

When MiroFish is selected, inspect the available installation and its configuration. It takes seed material and a prediction question and produces a simulation report. Use inputs and services authorized for this run. If the requested provider cannot run, identify the missing prerequisite and deliver the scenario brief with the run marked pending. Ordinary synthetic task walkthroughs can proceed independently. [MiroFish project](https://github.com/666ghj/MiroFish)

Return the conditions actually simulated, resulting hypotheses, and which behavior could discriminate between them in subsequent testing. Route hypotheses to the appropriate managers. Keep simulated group responses distinct from observations of someone navigating the interface.
